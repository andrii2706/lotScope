# LotScope

MVP-інструмент для компаній, що привозять авто з аукціонів США (IAAI, Copart).
Менеджер завантажує фото лота й дані з картки, а отримує звіт під брендом компанії:

- ШІ-оцінка пошкоджень за фото: деталі, сценарії ремонту, ризики, яких фото бракує;
- вилка вартості ремонту за цінами компанії (нормо-година, фарбування, тип запчастин);
- ціна під ключ: аукціон, логістика, мито, акциз, ПДВ, пенсійний збір, послуги;
- максимальна ставка, за якої клієнт зберігає задану вигоду відносно ринку;
- друк звіту в PDF з логотипом і контактами компанії;
- «Знайти лот»: за посиланням Copart/IAAI, номером лота чи VIN підставляє дані, фото й ціни продажів схожих лотів (потрібен ключ постачальника даних);
- звіт Carfax чи AutoCheck (PDF або скриншоти) — ШІ читає попередні ДТП, пробіг і статуси;
- темна, світла або системна тема;
- ролі: супер адмін, адмін компанії, менеджер з пошуку, технічний спеціаліст СТО, простий користувач (див. розділ «Ролі»);
  вхід паролем або через Google, сесія діє 8 годин;
  компанії створює супер адмін: він задає кількість місць, виставляє рахунки, може призупинити доступ і бачить журнал дій;
  адмін компанії запрошує й видаляє людей і бачить дії менеджерів та їхні звіти;
  звіти й налаштування компанії зберігаються в базі даних;
  оплата карткою через LiqPay з автосписанням або за рахунком;
  пошук і перегляд списку лотів безкоштовні, деталі лота наживо, історія за VIN і звіт відкриваються за аналіз;
- пошук активних лотів Copart та IAAI з фільтрами й медіаною продажів схожих авто;
- автоматична історія за VIN: попередні аукціони, титули й статуси NMVTIS, перевірка скручування пробігу;
- перевірка звіту експертом СТО: його правки стають уроками, які модель враховує в наступних аналізах.

«LotScope» — робоча назва.

## Запуск

Потрібен Node.js 20.9 або новіший.

```bash
npm install
cp .env.example .env.local   # впишіть ANTHROPIC_API_KEY та інші ключі
docker compose up -d         # локальна база Postgres
npm run db:migrate           # створює таблиці
npm run dev                  # http://localhost:3000 → «Зареєструвати компанію»
```

Для продакшену: `npm run build && npm start`, або розгортання на Vercel чи будь-якому
хостингу з Node.js. Змінні середовища:

| Змінна | Обов'язкова | Призначення |
|---|---|---|
| `ANTHROPIC_API_KEY` | так, для аналізу | Ключ Claude API. Без нього працює демо-режим. |
| `ANTHROPIC_MODEL` | ні | Модель для аналізу, за замовчуванням `claude-sonnet-5-5`. |
| `ANTHROPIC_EFFORT` | ні | Глибина міркувань моделі: `low`, `medium`, `high`, `xhigh` або `max`. Якщо модель не підтримує — приберіть. |
| `DATABASE_URL` | так | База Postgres: компанії, користувачі, оплати, уроки експерта. |
| `APP_URL` | для оплати | Публічна адреса сайту: на неї LiqPay надсилає підтвердження, а Google повертає після входу. |
| `ADMIN_EMAILS` | так, для першого супер адміна | Email супер адмінів через кому. Зареєструйтеся з такою поштою, і акаунт отримає роль супер адміна (консоль /admin). |
| `DATABASE_SSL` | ні | Для віддалених баз SSL увімкнено автоматично (без перевірки ланцюжка, це виправляє «self-signed certificate»). `off` вимикає SSL, `verify` вмикає сувору перевірку. |
| `SESSION_HOURS` | ні | Тривалість сесії в годинах, за замовчуванням 8. Після цього користувача розлогінює. |
| `SALES_CONTACT` | ні | Контакт для компаній, які хочуть підключитися (показується на сторінці реєстрації). |
| `LIQPAY_PUBLIC_KEY`, `LIQPAY_PRIVATE_KEY` | для оплати карткою | Ключі мерчанта LiqPay. Потрібні й для скасування автосписання. |
| `LIQPAY_SANDBOX`, `LIQPAY_SIGNATURE` | ні | `1` вмикає тестовий режим; `sha1` (за замовчуванням) чи `sha3-256`: алгоритм підпису запитів. |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | для входу через Google | OAuth-клієнт типу Web application. Redirect URI: `APP_URL/api/auth/google/callback`. |
| `INVOICE_DETAILS` | для рахунків | Реквізити ФОП чи ТОВ для оплати за рахунком. |
| `AUCTION_API_KEY` | ні | Ключ ліцензованого постачальника даних аукціонів (apiauctions.io). Вмикає автозаповнення лота, фото та ціни схожих продажів. Без нього — лише посилання для пошуку. |
| `AUCTION_API_URL` | ні | Адреса постачальника, за замовчуванням `https://apiauctions.io`. |
| `VINAUDIT_API_KEY`, `VINAUDIT_USER`, `VINAUDIT_PASS` | ні | VinAudit (NMVTIS): титули, статуси Salvage/Junk, страхові записи, пробіг. Близько $1 за запит. |

**Демо-режим.** Без ключа застосунок повністю працює, але опис пошкоджень у звіті —
заздалегідь підготовлений приклад, а не аналіз завантажених фото. Про це є попередження
на формі та у звіті. Розрахунок ціни під ключ у демо-режимі справжній.

## Перевірка

```bash
npm test        # розрахунок розмитнення, пенсійного збору, максимальної ставки
npm run lint
npm run build
```

Тести звіряють мито, акциз і ПДВ з опублікованими прикладами (Toyota RAV4 2020,
Tesla Model Y 2021).

Чого не перевірено: реальний виклик Claude API. Застосунок збирався й тестувався без
ключа, тому перший запуск з ключем варто зробити на кількох знайомих лотах і
порівняти оцінки з власним досвідом.

## Як це влаштовано

```
src/app/page.tsx              форма нового аналізу
src/app/report/[id]/page.tsx  звіт (екран і друк)
src/app/history/page.tsx      історія звітів
src/app/settings/page.tsx     бренд, тарифи, курси компанії
src/app/api/analyze/route.ts  серверний маршрут: перевірка даних і виклик Claude
src/lib/prompt.ts             інструкція для моделі та JSON-схема відповіді
src/lib/calc.ts               розмитнення, ціна під ключ, максимальна ставка
src/lib/normalize.ts          приведення відповіді моделі до очікуваної форми
src/lib/store.ts              клієнтський кеш звітів і налаштувань (дані в БД через /api/reports і /api/settings)
src/lib/roles.ts              ролі та матриця прав
```

ШІ відповідає лише за те, що видно на фото, і за вилку ремонту. Уся арифметика
(розмитнення, збори, максимальна ставка) рахується звичайним кодом у `calc.ts`,
тому її можна перевірити й покрити тестами.

Тема: темний або світлий інтерфейс (перемикач у шапці й у налаштуваннях) і світлий документ для друку. Кольори задані змінними
в `src/app/globals.css`; блок `@media print` перемикає їх на світлі, а сам друкований звіт
лежить у `src/components/PrintReport.tsx`. Колір бренду компанії підставляється в `AppShell`,
колір тексту на ньому підбирається автоматично (`src/lib/color.ts`).

Інтерфейс: Tailwind CSS 4, іконки `lucide-react`, шрифти Manrope та Unbounded
(лежать у проєкті, без звернень до зовнішніх серверів).

Фото стискаються в браузері до 1568 px перед відправленням. Ключ API живе тільки
на сервері й у браузер не потрапляє.

## Закладені правила та припущення

Розмитнення за правилами 2026 року:

- митна вартість = ставка + збір аукціону + доставка до кордону;
- мито 10 % (електромобілі 0 %);
- акциз = базова ставка × об'єм у літрах × коефіцієнт віку: бензин 50 € (понад 3,0 л — 100 €),
  дизель 75 € (понад 3,5 л — 150 €), електро — 1 € за кВт·год;
- коефіцієнт віку = рік розрахунку − рік випуску − 1, від 1 до 15;
- ПДВ 20 % від суми митної вартості, мита й акцизу;
- пенсійний збір 3 / 4 / 5 % від вартості без ПДВ, пороги 165 і 290 прожиткових
  мінімумів (3328 грн з 01.01.2026), електромобілі звільнені.

Що треба мати на увазі:

- Тарифи на логістику, збір аукціону, послуги й ціни ремонту в налаштуваннях —
  приклади. Кожна компанія має замінити їх своїми.
- Збір аукціону рахується спрощено (відсоток плюс фіксована частина). Реальні
  таблиці зборів IAAI і Copart ступінчасті, тож суму варто уточнювати у звіті вручну.
- Гібрид рахується як бензиновий двигун. Гібриди із зарядкою від розетки мають
  окремі правила й поки не підтримуються.
- Курси валют задаються вручну в налаштуваннях.
- Ставки мита й акцизу зашиті в `calc.ts`. Якщо закон зміниться, оновіть їх там.

## Ролі

| Роль | Що може |
|---|---|
| Супер адмін | Користується всією логікою застосунку без списання аналізів (пошук, аналіз, звіти, PDF, експертні висновки) і, окрім того, створює компанії та адмінів, змінює кількість місць, виставляє й підтверджує рахунки, призупиняє доступ, додає й видаляє користувачів, бачить статистику по компаніях і журнал усіх дій. Не шукає лоти й не аналізує. |
| Адмін компанії | Запрошує й видаляє користувачів у межах місць, бачить дії менеджерів («Активність») і всі звіти компанії, налаштування компанії, тариф і оплату. Кількість місць змінити не може. |
| Менеджер з пошуку | Пошук лотів, аналіз, свої звіти, збереження й PDF. |
| Технічний спеціаліст СТО | Звіти всієї компанії, експертний висновок, уроки для моделі. |
| Простий користувач | Публічна реєстрація для ознайомлення: пошук і перегляд звіту. Збереження й PDF лише з особистою підпискою. |

Збереження й PDF вимагають активної підписки (для всіх ролей). Права перевіряються на сервері в `requireUser(permission)`, а приховування кнопок і заборона друку в браузері лише косметичні: скриншот чи друк обійти не можна повністю.

Перший супер адмін: додайте його пошту в `ADMIN_EMAILS` і зареєструйтеся з нею.

## Обмеження MVP і наступні кроки

Звіти й налаштування компанії зберігаються в базі даних (фото звітів теж, у таблиці `report_photos`: для великих обсягів пізніше варто винести їх у файлове сховище). Для продажу компаніям далі потрібні:

1. Вхід і кабінет компанії: база даних (наприклад, Postgres + Prisma), кілька
   менеджерів на одну компанію, спільна історія.
2. Посилання на звіт для клієнта замість PDF.
3. Облік використання й оплата: підписка або пакети звітів.
4. Перевірити інтеграцію з постачальником даних аукціонів на реальному ключі.
5. Автоматична історія за VIN через API (наприклад, VinAudit) на додачу до ручного Carfax.
6. Реальні таблиці зборів аукціонів і тарифів доставки за штатами та портами.
7. Калібрування оцінок ремонту на реальних кошторисах компанії.

## Розгортання на Vercel

1. Створіть Postgres: Neon або Supabase (також через Vercel Marketplace). Для `DATABASE_URL` беріть pooled-рядок підключення.
2. Один раз виконайте міграцію зі свого комп'ютера: `DATABASE_URL="<рядок>" npm run db:migrate`.
3. Завантажте проєкт на GitHub і імпортуйте його у Vercel (Framework: Next.js, налаштування за замовчуванням).
4. Схема бази створюється автоматично під час кожного білду на Vercel (`vercel.json` запускає `npm run vercel-build`, тобто міграцію, а потім `next build`). Змінна `DATABASE_URL` має бути задана для Production і Preview до першого деплою.
5. У Settings → Environment Variables додайте змінні з `.env.example`: `DATABASE_URL`, `APP_URL` (адреса сайту, наприклад `https://lotscope.vercel.app`), `ANTHROPIC_API_KEY`, `ADMIN_EMAILS`, `LIQPAY_*`, `GOOGLE_*` та інші потрібні. Після зміни змінних зробіть Redeploy.
5. У Google Cloud додайте Redirect URI `APP_URL/api/auth/google/callback`. У кабінеті LiqPay сервер сам передає `server_url`, окремо вказувати його не треба.
6. Ліміти Vercel: тіло запиту до функції до 4,5 МБ (тому фото стискаються, а великий PDF Carfax краще замінити скриншотами), тривалість аналізу до 120 с потребує увімкненого Fluid Compute або плану Pro.
